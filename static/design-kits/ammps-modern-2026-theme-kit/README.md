# AMMPS Modern 2026 - Theme Kit

Kit frontend autonome inspiré de la mockpage moderne validée dans la conversation.

## Contenu
- `mockpage.html` : prévisualisation autonome et responsive
- `theme.css` : tokens, fondations et composants
- `theme.js` : navigation mobile, recherche, filtres et FAQ
- `design-tokens.json` : source de vérité du design
- `PROMPT-IA.md` : prompt pour appliquer le thème à un autre projet
- `INTEGRATION.md` : instructions HTML, React, Vue, Angular et Laravel

## Prévisualisation
Ouvrez simplement `mockpage.html` dans un navigateur moderne. Aucune installation et aucune connexion Internet ne sont nécessaires.

## Intégration rapide
```html
<link rel="stylesheet" href="theme.css">
<script src="theme.js" defer></script>
```

## Important
Le kit utilise une marque générique et ne contient ni logo officiel, ni image, ni code propriétaire de l’AMMPS. Remplacez les contenus de démonstration par ceux de votre projet.
