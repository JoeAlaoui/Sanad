# Kits de design sources

Ces trois kits, fournis par l'utilisateur, ont servi à construire les thèmes visuels
correspondants dans `static/style.css` (blocs `[data-theme="pastel"]`,
`[data-theme="ammps-vert"]`, `[data-theme="ammps-moderne"]`). Conservés ici à titre de
référence/traçabilité — non chargés par l'application au runtime.

| Dossier | Thème SANAD correspondant |
|---|---|
| `Pastel/` | Pastel |
| `ammps-inspired-theme-kit/` | AMMPS Vert Institutionnel |
| `ammps-modern-2026-theme-kit/` | AMMPS Moderne 2026 |
