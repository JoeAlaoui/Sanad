🔗 Partager SANAD sur le réseau local

Par défaut, SANAD n'est accessible que depuis cet ordinateur. Pour qu'un collègue connecté au même réseau local (même Wi-Fi/switch que ce poste) puisse y accéder avec le lien ci-dessous, activez le partage réseau. Chaque utilisateur devra se connecter avec son propre compte SANAD. Ce changement s'applique immédiatement, sans redémarrage.

Changer le port redémarre automatiquement l'application (quelques secondes d'interruption) — laisser inchangé pour une bascule instantanée.

Lien à transmettre à vos collègues sur ce réseau :

⚠️ Le partage réseau expose SANAD à toute personne connectée au même réseau (pas à Internet). Chacun reste soumis à l'authentification et aux rôles habituels.

Import par section — Mode Direct GLPI ou Mode CSV

        
Choisir le type de données puis le mode d'import. Le Mode Direct interroge l'API GLPI configurée (Administration → Intégrations GLPI) sans fichier intermédiaire ; le Mode CSV conserve la traçabilité fichier pour l'audit qualité. Les deux modes alimentent exactement les mêmes données.

        

          
          
        

        

          
          
        

        

          
          
        

        

          

            
            
          

          

        

        

      


      

        
🗓️ Import tickets bruts (ticket par ticket)

        
Export GLPI brut — une ligne par ticket, avec colonnes ID, Statut, Date d'ouverture, Priorité, Catégorie, Type, Technicien... Distinct de l'import consolidé ci-dessus. Alimente la répartition par Type/Priorité et la heatmap de charge (jour × heure), calculée à partir des horodatages réels — ré-importer régulièrement pour la tenir à jour (les tickets déjà connus sont mis à jour, pas dupliqués).

📧 Notifications par email — rappel automatique (tâche planifiée)

        
Sans configuration SMTP, le rappel de rapport non envoyé reste un bandeau visible à l'ouverture de l'app (limite déjà documentée dans le README). En renseignant un serveur SMTP ici, une tâche planifiée externe (Windows Task Scheduler, cron...) peut appeler /api/system/reminder-check une fois par jour pour un envoi réel, même app fermée.

🛡️ RGPD — données personnelles

        
Recherche un nom (demandeur GLPI ou raison sociale/opérateur PCHC) dans les données stockées, pour exercer un droit d'accès ou d'effacement. Ne couvre pas les feuilles agrégées mensuelles Moussanada (totaux par étiquette, pas d'enregistrements individuels).

        

          
          
          
        

        

      


      

        
🔌 Intégrations — GLPI (API REST)

        
Connexion directe à l'API REST GLPI (apirest.php), en complément de l'import CSV existant qui reste pleinement fonctionnel. Nécessite un App-Token (Configuration → Générale → API, dans GLPI) et un User-Token (préférences du compte GLPI utilisé pour l'import).

        

        

        

        

        

          
          
        

        


        

          
Import direct par profil
